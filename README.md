# Yatube API

REST API для социальной сети Yatube — сервиса для публикации личных
дневников. Пользователи могут публиковать записи, комментировать чужие
публикации, объединять записи по сообществам и подписываться на других
авторов.

## Возможности API

- Публикации: получение списка, создание, просмотр, редактирование и
  удаление отдельной публикации.
- Комментарии к публикациям: получение списка, создание, просмотр,
  редактирование и удаление отдельного комментария.
- Сообщества: получение списка сообществ и информации об отдельном
  сообществе (доступно только для чтения).
- Подписки: подписка на других пользователей и получение списка своих
  подписок с возможностью поиска по имени автора.
- Аутентификация по JWT-токену.

Изменять или удалять чужой контент нельзя — доступ на запись есть только у
автора объекта, остальным доступно только чтение. Неаутентифицированным
пользователям доступно только чтение публикаций, комментариев и сообществ;
эндпоинт подписок требует аутентификации для любых запросов.

Документация в формате Redoc доступна по адресу `/redoc/` после запуска
проекта.

## Установка

Клонируйте репозиторий и перейдите в его директорию:

```bash
git clone https://github.com/kenny0MG/api-final-yatube-ad.git
cd api-final-yatube-ad
```

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
```

Установите зависимости:

```bash
python3 -m pip install --upgrade pip
pip install -r requirements.txt
```

Выполните миграции и запустите сервер:

```bash
cd yatube_api
python3 manage.py migrate
python3 manage.py runserver
```

## Примеры запросов

Получение JWT-токена:

```
POST /api/v1/jwt/create/
```

```json
{
    "username": "anton",
    "password": "chekhov"
}
```

Ответ:

```json
{
    "refresh": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
    "access": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9..."
}
```

Публикация новой записи (заголовок `Authorization: Bearer <access-токен>`):

```
POST /api/v1/posts/
```

```json
{
    "text": "Текст новой публикации",
    "group": 1
}
```

Получение списка публикаций с пагинацией:

```
GET /api/v1/posts/?limit=5&offset=10
```

Подписка на пользователя:

```
POST /api/v1/follow/
```

```json
{
    "following": "leo"
}
```
